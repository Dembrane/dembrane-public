# dembrane-public

Public [Claude Code](https://claude.com/claude-code) plugins from [dembrane](https://dembrane.com). Safe for anyone to install: no internal data, no workspace wiring. Today it's a marketing toolkit for the team.

## Install

In Claude Code, run:

```
/plugin marketplace add dembrane/dembrane-public
/plugin install marketing@dembrane-public
```

No GitHub account needed. To update later, run `/plugin marketplace update dembrane-public`.

## What's inside

**`marketing` plugin**

- **styled-email** — describe an email in plain language and get on-brand, Outlook-safe HTML ready to paste into MailerLite (or any email tool). Handles dembrane's palette, DM Sans, the categorical accent system, and the required unsubscribe + address footer.

## How it works

You talk naturally; the right skill fires on what you're doing. For email: describe the send (the topic, the key facts, the button link), and Claude builds it, shows you a preview, and hands you the final HTML and a subject line. You paste it into a MailerLite Custom HTML campaign.
